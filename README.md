# 浜名湖うなぎ 非公式紹介ガイド (Lake Hamana Eel Unofficial Web Guide)

うなぎ養殖発祥の地・静岡県浜名湖が誇るうなぎ文化、120有余年の伝統、関東風と関西風の交差点、美味しさの秘密を解説する非公式Webサイトです。
GitHub Pagesに対応した静的サイト（HTML / CSS / JavaScript）として設計されています。

---

## 🌟 サイトの主な特徴・コンテンツ

1. **和モダンなプレミアムデザイン**
   - 漆の朱色（`#bd382b`）と琥珀タレの黄金色（`#c98a2c`）、深藍（`#1b3858`）を基調とした上質な和のビジュアル。
   - 美しいタイポグラフィ（Google Fonts: Shippori Mincho / Noto Serif JP / Noto Sans JP）。
   - 高解像度の写真アセット（うな重、炭火焼きの職人技、夕景の浜名湖、白焼・ひつまぶし御膳）。

2. **充実の解説コンテンツ**
   - **歴史と発祥**: 明治33年、服部倉治郎による日本初の養鰻成功ストーリーとタイムライン。
   - **4つの秘密**: 地下水掛け流しの「立場（泥抜き）」、年間日照2,300時間、厳選飼料、薄皮と脂の黄金比。
   - **東西の交差点**: 関東風（背開き・蒸し）と関西風（腹開き・地焼き）のインタラクティブ比較タブ。
   - **4大名物料理**: 蒲焼・白焼・ひつまぶし・肝焼き/うなぎボーンの美味しい味わい方と薬味。
   - **栄養と健康**: ビタミンA・B群、DHA/EPA、コラーゲンとスタミナの科学。
   - **4大エリア観光マップ**: 浜松駅・かんざんじ温泉・弁天島舞阪・三ヶ日奥浜名湖。
   - **よくある質問（FAQ）**: 白焼と蒲焼の選び方、お取り寄せの美味しい温め方など。

3. **インタラクティブ機能**
   - **おすすめ食べ方診断**: 気分と食感の好みに応じてぴったりの料理と食べ方をご提案。
   - **浜名湖うなぎ検定クイズ**: 全4問のクイズに答えて「修了認定証」と称号を獲得！
   - レスポンシブナビゲーション・モバイルドロワー対応。

## 🚀 GitHub Pages への公開手順

本リポジトリには、GitHub Actionsによる自動デプロイワークフロー（`.github/workflows/deploy.yml`）が含まれています。

### 方法1: GitHub Actions による自動デプロイ（推奨）

1. 本リポジトリの変更を `main` ブランチにコミット＆プッシュします。
2. GitHubのリポジトリページで **Settings** > **Pages** を開きます。
3. **Build and deployment** の **Source** で **「GitHub Actions」** を選択します。
4. プッシュすると自動的に `.github/workflows/deploy.yml` が実行され、数分でサイトが公開されます。
5. 公開URL形式: `https://<あなたのGitHubユーザー名>.github.io/<リポジトリ名>/`

### 方法2: ブランチ指定によるデプロイ

1. GitHubのリポジトリページで **Settings** > **Pages** を開きます。
2. **Build and deployment** の **Source** で **「Deploy from a branch」** を選択します。
3. **Branch** で `main` / `/ (root)` を選択して **Save** をクリックします。

## 💻 ローカルでのプレビュー方法

Node.jsやPython等の簡易サーバーで即座に確認できます。

```bash
# Python 3 を使用する場合
python3 -m http.server 8080

# または npx serve を使用する場合
npx serve .
```

ブラウザで `http://localhost:8080` を開いてご確認ください。
